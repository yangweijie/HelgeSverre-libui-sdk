# Plan: Replace native FFI with kingbes/phpc

## Goal
Replace all direct `\FFI::*` calls across the codebase with `kingbes/phpc` safety wrappers, eliminating the class of bugs documented in AGENTS.md: double-free, use-after-free, dangling GC closures, buffer overflows, and memory leaks.

## Scope
- 8 source files with ~87 FFI touchpoints
- 7 `\FFI::cdef()` bridge loaders
- Core `Ffi.php` patch (closure retention, string handling, init/uninit)

## Migration Map

| Native FFI | phpc Replacement | Files Affected |
|---|---|---|
| `\FFI::cdef($header, $lib)` | `Library::permit($lib)` + `Library::load($lib, $header)` | Ffi.php, WebView.php, Surface.php, Tray.php, Audio.php, Toast.php, GlobalHotkey.php, ContextMenu.php |
| `\FFI::memcpy($to, $from, $size)` | `Memory::copy($to, $from, $size)` | Tray.php |
| `\FFI::addr($ptr)` | `Memory::addr($ptr)` | Ffi.php, WebView.php, Tray.php |
| `\FFI::string($ptr)` | `TypeCast::fromString($ptr)` | Ffi.php |
| `\FFI::sizeof($ptr)` | `Memory::sizeof($ptr)` | Ffi.php |
| `\FFI::cast('type', $ptr)` | `TypeCast::castIn($ffi, $ptr, 'type')` | Surface.php, Tray.php, WebView.php |
| `\FFI::isNull($ptr)` | `Pointer::isNull($ptr)` | Tray.php |
| `$ffi->new('type')` | `TypeCast::toInt()` / `$ffi->new()` (keep for structs) | Ffi.php, Tray.php, WebView.php |
| `self::$retained[] = $cb` | `Callback::wrap($ffi, $cb, 'void(*)(...)')` | Ffi.php |

## Implementation Steps

### Step 1: Core Ffi.php patch (`patches/helgesverre/libui/src/Ffi.php`)

**Changes:**
1. Add `use Kingbes\Phpc\{Library, Memory, TypeCast, Pointer, Callback, SafeCall};` imports
2. Replace `\FFI::cdef($header, $libPath)` in `init()` and `debugInit()` with `Library::permit('libui')` + `Library::load('libui', $header)` — note: `Library::load()` resolves lib path internally, so `libPath()` result is used differently
3. Replace `\FFI::addr($opts)` with `Memory::addr($opts)` in `init()`
4. Replace `\FFI::sizeof($opts)` with `Memory::sizeof($opts)` in `init()`
5. Replace `\FFI::string($err)` with `TypeCast::fromString($err)` in `init()`
6. Replace `self::$retained[] = $cb` pattern with `Callback::wrap()` in `onShouldQuit()`, `timer()`, `queueMain()`
7. Replace `self::$retained = []` in `uninit()` with proper `Callback::release()` calls
8. Update `ownedString()` and `borrowedString()` to use `TypeCast::fromString()`
9. Add `use Kingbes\Phpc\Library;` and register libui path with `Library::permit()`

**Key constraint:** `Ffi::get()` must still return `\FFI` — this is the public API. phpc is used internally only.

### Step 2: Bridge loaders (7 files)

Each file has a `loadXxx()` method that calls `\FFI::cdef()`. Replace with:

```php
// Before
$this->ffi = \FFI::cdef($header, $libPath);

// After
use Kingbes\Phpc\Library;
Library::permit($libName);
$this->ffi = Library::load($libName, $header);
```

Files and their bridge names:
1. **WebView.php** (`loadBridge()`, `loadPebView()`) — `webview_bridge`, `pebview`
2. **Surface.php** (IME bridge) — `ime_bridge`
3. **Tray.php** (`ffi()` static) — `pebview` (reuses PebView)
4. **Audio.php** — `audio_bridge`
5. **Toast.php** — `toast`
6. **GlobalHotkey.php** — `hotkey`
7. **ContextMenu.php** — `context_menu`

### Step 3: Memory operations (Tray.php)

Replace in `Tray.php`:
- `\FFI::memcpy($iconNative, $this->iconPath, ...)` → `Memory::copy($iconNative, $this->iconPath, ...)`
- `\FFI::memcpy($tipNative, $this->tooltip, ...)` → `Memory::copy($tipNative, $this->tooltip, ...)`
- `\FFI::memcpy($textBuf, $text, $textLen)` → `Memory::copy($textBuf, $text, $textLen)`
- `\FFI::isNull($this->trayHandle)` → `Pointer::isNull($this->trayHandle)`
- `\FFI::cast('void*', $hwnd)` → `TypeCast::castIn($ffi, $hwnd, 'void*')`
- `\FFI::addr($textBuf)` → `Memory::addr($textBuf)`

### Step 4: Type casts (Surface.php, WebView.php)

Replace in **Surface.php**:
- `Ffi::get()->cast('void*', $areaNsViewInt)` → `TypeCast::castIn(Ffi::get(), $areaNsViewInt, 'void*')`

Replace in **WebView.php**:
- `Ffi::get()->uiWindowContentSize($w, \FFI::addr($wOut), \FFI::addr($hOut))` → use `Memory::addr()` for the two addr calls

### Step 5: Update patches/ system

The `patch.php` script copies `patches/` into `vendor/`. Since we're modifying `patches/helgesverre/libui/src/Ffi.php`, the new version will be applied on next `composer install` or `php patch.php`.

**No changes needed to patch.php** — it already handles this file.

## What Stays the Same

- `Ffi::get()` still returns `\FFI` — no API break
- All widget classes (Control, Window, Box, etc.) — unchanged
- `src/Composite.php` — only has `\FFI\CData` return type, unchanged
- Test suite — should pass without modification (tests mock or skip FFI)
